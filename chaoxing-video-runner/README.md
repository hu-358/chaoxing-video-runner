# 指定课程视频顺序播放器（Microsoft Edge）

当前版本：`1.0.3`

`1.0.3` 根据课程中的真实完成节点修复了漏判：超星会先在视频外层容器添加 `ans-job-finished`，内部图标的文字可能稍后才更新。新版同时检查外层完成类和内部辅助标签，并在确实未确认时把DOM诊断信息写入日志。

`1.0.2` 修复了视频结束后页面已显示任务点完成、但扩展仍读取旧节点并误判为未完成的问题。新版会重新查询最新任务节点，并在结束后最多轮询45秒确认服务器状态。

`1.0.1` 修复了播放器控件延迟加载、以及已选中倍速显示为“2x, 选择”时被错误判断为没有官方2×的问题。

这是一个只绑定到本地配置课程的历史版 Edge 扩展。公开版本已移除原始课程和班级标识；使用前请编辑 `content.js` 顶部的 `CONFIG`：

- `courseId`: 将 `REPLACE_WITH_COURSE_ID` 替换为当前课程 ID
- `clazzId`: 将 `REPLACE_WITH_CLASS_ID` 替换为当前班级 ID
- 视频任务总数：57

扩展使用播放器公开提供的 2× 选项，自动静音，从第一个仍未完成的视频任务开始顺序播放。它不会向前跳播、伪造时间或调用隐藏的完成接口；只有页面显示“任务点已完成”后，才把视频视为完成。

## 安装

1. 将整个 `chaoxing-video-runner` 文件夹保留在固定位置，不要在安装后移动或删除。
2. 打开 Microsoft Edge，在地址栏输入 `edge://extensions/`。
3. 打开页面左侧或右侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择本文件所在的 `chaoxing-video-runner` 文件夹；应当能直接看到其中的 `manifest.json`。
6. 确认扩展列表出现“指定课程视频顺序播放器”，且开关为启用状态。

本扩展不需要填写账号、密码，也不会读取浏览器保存的密码。请先在 Edge 中正常登录超星。

## 使用

1. 在 Edge 中打开已配置课程的“章节详情/学生学习页面”。页面地址中的 `courseId` 和 `clazzid` 必须与本地 `CONFIG` 一致。
2. 刷新一次页面，让新安装的扩展注入。
3. 页面右上角会出现“指定课程 · 视频播放器”面板。
4. 点击“开始 / 继续”。扩展会：
   - 查找第一个服务器仍标记为未完成的视频章节；
   - 跳过 PDF、章测、作业和其他非视频内容；
   - 从视频开头真实播放；
   - 选择播放器公开提供的官方 2×；
   - 自动静音；
   - 检测到“任务点已完成”后进入下一个视频；
   - 页面刷新或 Edge 重启后自动恢复仍在运行的任务。
5. 点击“暂停”会立刻暂停当前视频并保存状态；之后点击“开始 / 继续”即可恢复。
6. 保持 Edge 打开并保证电脑不休眠。建议只保留一个该课程的学习标签页，避免多个页面同时修改进度。

## 重试与跳过规则

- 首次播放失败后等待10秒，再开始重试。
- 每个视频最多重试5次。
- 第5次重试后仍未核验为完成时，本轮会跳过该视频并在日志中以红色显示。
- 跳过不等于完成，进度条不会把它算入57个已完成视频。
- 一轮结束后再次点击“开始”，扩展会清空本轮的跳过列表，只重新处理服务器仍标记为未完成的视频。

因此，如果发生跳过，扩展会诚实地显示“本轮结束但仍有任务未完成”，不会错误报告57/57。

## 面板说明

- **状态**：当前运行、等待、重试或结束原因。
- **视频任务进度**：根据课程目录中非测试任务点的服务器状态计算。
- **章节/视频**：当前处理的位置。
- **播放**：当前时间与视频总时长。
- **跳过**：本轮达到重试上限的数量。
- **运行日志**：开始、完成、重试、跳过和异常记录。

## 常见问题

### 页面没有出现面板

确认当前地址是 `mooc1.chaoxing.com/mycourse/studentstudy`，然后刷新页面。再到 `edge://extensions/` 检查扩展是否启用。

### 视频无法自动播放

先在页面上手动点击一次任意位置，再点击面板中的“开始 / 继续”。静音媒体通常允许自动播放，但浏览器策略或站点弹窗仍可能阻止播放。

### 进度长期不变化

查看面板日志。网络异常、登录失效、平台验证或课程配置变化都可能导致进度不上报。扩展会按规则重试，达到上限后跳过并记录名称。

### Edge 重启后没有继续

重新打开同一课程的学生学习页面。扩展只能在课程页面存在时播放；它不会自行启动 Edge 或替你登录。

### 更新扩展文件后如何生效

打开 `edge://extensions/`，在该扩展卡片中点击“重新加载”，随后刷新课程页面。
