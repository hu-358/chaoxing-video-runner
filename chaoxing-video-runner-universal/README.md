# 学习通课程视频播放器（通用版）

当前版本：`2.0.0`

这是独立于《创业基础》专用版的新扩展。它只处理使用者手动打开的当前课程，不会自动遍历账号课程列表。每个课程标签页独立扫描和播放，因此不同课程可以并行；同一门课程通过标签页锁避免重复运行。

扩展仅执行真实视频播放：读取播放器公开提供的倍速菜单、从视频开头播放，并以页面实际完成标记作为结果。它不向前跳播、不伪造时长、不调用隐藏完成接口，也不处理测试、作业或考试。

## 安装

1. 保留整个 `chaoxing-video-runner-universal` 文件夹，安装后不要移动或删除。
2. 在 Microsoft Edge 地址栏打开 `edge://extensions/`。
3. 打开“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择本文件所在的 `chaoxing-video-runner-universal` 文件夹。
6. 确认扩展列表中出现“学习通课程视频播放器（通用版）”，版本为 `2.0.0`。

旧的《创业基础》专用版文件可以保留，但在使用通用版处理《创业基础》时，请在扩展管理页禁用专用版。两个版本不能同时控制同一个课程页面；通用版检测到旧版面板时会拒绝启动。

通用版会申请访问 `*.chaoxing.com`，用于兼容不同学校入口、课程门户和学习页面。它不读取或保存账号密码。

## 单课程使用

1. 在 Edge 中正常登录学习通。
2. 手动进入需要处理的课程，并打开任意一个“章节详情/学生学习页面”。地址通常包含 `/mycourse/studentstudy`、`courseId` 和 `clazzid`。
3. 首次安装后刷新一次课程学习页面。
4. 页面右上角出现“学习通视频播放器 · 通用版”面板。
5. 在倍速下拉框中选择设置：
   - `自动最高倍速`：默认，使用当前视频公开菜单中的最高速度；
   - `最高1× / 1.25× / 1.5× / 2×`：使用不高于该值的最高公开速度。
6. 点击“开始 / 继续”。扩展会先依次打开章节建立视频清单，然后从清单中的第一个未完成视频开始播放。
7. 点击“暂停”会保存当前课程状态并暂停视频，再次点击“开始 / 继续”可恢复。

## 扫描规则

- 开始后先读取当前课程的全部叶子章节。
- 标题明显属于测试、测验、考试、作业、讨论或问卷的章节不会打开。
- 其余章节会被短暂打开，以检查其中是否包含视频播放器。
- PDF、音频及其他没有视频播放器的内容不进入视频清单。
- 扫描期间不会主动播放视频或提交任何非视频任务。
- 视频总数只有扫描完成后才准确，因此开始阶段进度会逐步增加。

## 播放和完成判断

- 每个视频从开头播放并自动静音。
- 扩展从播放器的公开菜单中选择倍速。
- 完成判断同时检查视频外层 `ans-job-finished` 标记和内部“任务点已完成”标签。
- 视频播放结束后最多等待45秒，让平台完成进度上报。
- 全部视频遍历结束后，扩展会再次逐节打开视频章节，重新核验服务器呈现的完成状态。
- 只有最终核验到的项目才计入最终完成数。

## 多课程并行

1. 手动打开第一门课程的学习页面并点击“开始”。
2. 新建标签页，手动打开另一门课程并点击“开始”。
3. 不同课程拥有独立的扫描、播放、倍速、重试、日志和进度状态。
4. 每个面板的“已识别课程”区域会显示曾打开过的课程及最近状态。
5. 不要在两个标签页同时启动同一门课程；扩展会让后启动的标签页进入观察状态。

多课程同时播放会增加网络、CPU和内存占用。如果发生卡顿，应减少并行课程数量；卡顿超过30秒会进入重试逻辑。

## Edge重启和页面刷新

- 如果课程标签页被Edge自动恢复，扩展会重新扫描该标签页中的课程，然后从第一个未完成视频开始。
- 没有重新打开的课程不会自行启动。
- 扩展不能自行启动Edge、恢复未打开的标签页或替使用者登录。

## 重试、跳过与人工验证

- 播放、播放器加载或章节打开失败后等待10秒。
- 每个视频最多重试5次。
- 超过上限后记录失败并跳过该视频，继续当前课程的下一项。
- 跳过不等于完成，最终进度不会把该视频计为完成。
- 一轮结束后再次点击“开始”，会重新扫描课程并重新处理服务器仍显示未完成的视频。
- 检测到验证码、人脸识别、身份验证或禁止切屏提示时，只停止当前课程；其他课程标签页继续运行。
- 人工完成验证后，可回到对应标签页点击“开始 / 继续”。

## 控制面板

- **开始 / 继续**：开始新扫描或恢复当前课程。
- **暂停**：暂停当前课程，不影响其他课程。
- **导出失败**：下载当前课程的失败项目和运行日志JSON文件。
- **倍速选择**：按课程保存；播放中的视频会在下一次检查时应用新设置。
- **视频进度**：扫描完成后显示实际发现的视频总数和已完成数。
- **扫描进度**：当前已检查章节数和待检查章节总数。
- **已识别课程**：显示曾打开并被扩展识别的课程，不代表扩展会主动打开它们。

## 常见问题

### 页面没有面板

确认页面地址包含 `/mycourse/studentstudy`，然后刷新页面。在 `edge://extensions/` 中确认安装的是通用版且已启用。

### 一直停留在扫描阶段

课程目录或章节内容可能加载缓慢。查看日志中的具体章节；扩展会自动重试。人工验证弹窗会停止当前课程。

### 同一课程已在另一个标签页运行

关闭或暂停另一标签页。标签页异常关闭后，锁最多约20秒失效，随后可重新点击“开始”。

### 最终完成数低于扫描时显示的完成数

最终数字只统计第二次逐节核验成功的项目。查看失败日志；再次点击“开始”可重新扫描并重试未完成视频。

### 修改文件后如何更新

打开 `edge://extensions/`，在通用版扩展卡片上点击“重新加载”，然后刷新每个已打开的课程学习页面。
