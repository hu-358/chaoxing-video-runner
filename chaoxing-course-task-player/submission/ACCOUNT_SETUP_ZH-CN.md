# Microsoft Edge 开发者账号开通步骤

## 注册前准备

- 使用你本人控制的 Microsoft 账号，并开启双重验证。
- 账号类型选择 **Individual（个人）**；提交后账号类型通常不能直接更改。
- 对外发布者名称填写 **HuZaiming**。
- 支持邮箱填写 **huzaiminghuzaiming@outlook.com**。
- Microsoft 要求的法定姓名、地址、电话或身份材料应填写真实信息；这些资料用于平台验证，不等于商店页面必须公开展示实名。

## 注册与建项

1. 打开 Microsoft Partner Center 的 Edge 扩展开发者注册页。
2. 使用 Microsoft 账号登录，加入 Microsoft Edge Program。
3. 国家或地区选择中国大陆，账号类型选择 Individual。
4. 在可用性检查通过后，将 Publisher display name 设置为 HuZaiming。
5. 完成平台要求的邮箱、电话或身份验证。
6. 创建新扩展，上传 `release/chaoxing-course-task-player-edge-v2.2.0.zip`。
7. 可见性选择 Public，市场先仅选择 China。
