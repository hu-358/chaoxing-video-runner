学习通课程任务播放器（通用版）

生效日期：2026年9月4日

摘要：扩展不使用开发者服务器，不包含广告或分析工具，不向开发者或第三方传输课程数据；运行状态仅保存在用户当前的 Microsoft Edge 浏览器本地。

1. 适用范围与发布者

本政策适用于 HuZaiming 发布的“学习通课程任务播放器（通用版）”Microsoft Edge 扩展。联系邮箱：huzaiminghuzaiming@outlook.com。

2. 处理的数据

在用户完成首次确认、主动登录并打开课程后，扩展会读取课程名称、课程与班级标识、章节名称、视频或文档任务名称、任务完成状态和播放器进度；并在扩展本地存储中保存上述任务状态、用户设置、失败原因和运行日志。

扩展不读取、保存或传输学习通密码、Cookie、手机号、真实姓名、身份证件或支付信息。

3. 目的、存储与传输

数据仅用于执行用户主动发起的课程任务处理、显示进度、避免同课程重复运行、恢复非运行设置和本机排错。数据存储于 Microsoft Edge 提供的本地扩展存储中，不会由扩展同步到开发者服务器。扩展不出售、共享或用于广告、分析、画像及自动化决策。

4. 保存期限与用户控制

数据保留至用户清除相应数据或卸载扩展。用户可在课程面板中清除当前课程数据，在扩展菜单中清除全部扩展数据，也可主动导出失败日志。导出的文件由用户自行保管。

5. 权限

  • storage：保存首次确认、运行设置、课程状态和本地日志。
  • notifications：任务完成或失败暂停时显示不含课程名称的通用系统通知。
  • 学习通 HTTPS 页面访问：读取课程任务结构并控制页面内的官方视频播放器和文档查看器。扩展不在其他网站运行。

6. 未成年人

本扩展不专门面向儿童，不要求用户提供年龄，也不会向开发者传输未成年人数据。未成年人应在监护人指导下，并在学校和课程规则允许的范围内使用。

7. 第三方网站

核心功能不连接开发者或分析服务。用户主动访问 GitHub 产品、源代码或支持页面时，GitHub 可能依据其自身政策处理访问日志；访问这些页面不是扩展核心功能所必需。

8. 安全与政策更新

扩展不加载或执行远程代码。若未来增加新的数据类型、服务器、分析、广告或支付功能，将先更新本政策与商店披露，并在必要时重新征得确认。

本扩展为独立开发的非官方工具。
