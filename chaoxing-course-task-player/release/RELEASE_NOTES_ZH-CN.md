# 学习通课程任务播放器（通用版）2.2.0

> Edge 商店候选版：本版本尚未获得 Microsoft Edge 加载项商店认证或推荐。

本扩展为独立开发的非官方工具。

## 本次更新

- 新增首次使用说明与明确确认，未确认时不处理或保存课程状态。
- 每次打开或刷新课程页面后保持暂停，必须由用户再次点击“开始 / 继续”。
- 页面访问范围收紧为学习通 HTTPS 课程学习页和官方文档查看器。
- 加入本地数据清除、内置隐私说明和完全离线的审核演示。
- 通知改用不含课程、章节或任务名称的通用文案。
- 合并 2.1.7 的后台生命周期计时、播放器停滞判断和实例化课程锁修复。
- 提供 Edge 商店文案、权限说明、审核备注、截图和可复现构建脚本。

## 安装包

- 文件：`chaoxing-course-task-player-edge-v2.2.0.zip`
- SHA-256：`e2629500f956d319de0b1836051827c6a1aaea26759708066171c8519cb86fe6`
- 商店送审修订：补充简体中文默认语言元数据，不改变扩展功能。

在 Microsoft Edge 中打开 `edge://extensions/`，启用开发人员模式，解压 ZIP 后选择“加载解压缩的扩展”。正式商店版本发布后，普通用户应优先通过 Edge 加载项商店安装。

## 使用边界

- 不处理考试、测验、作业、讨论或问卷。
- 不绕过验证码、人脸识别、身份验证或禁止切屏提示。
- 不构造隐藏完成请求；完成状态以课程页面重新呈现的结果为准。
- 无开发者服务器、广告、分析工具或远程代码。
- 用户应自行确认使用方式符合学习通、所在学校和具体课程的规则。
