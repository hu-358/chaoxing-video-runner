# 学习通课程任务播放器（通用版）

当前版本：`2.1.2`

这是从通用版 `2.1.1` 独立复制出的新版本。所有旧目录均保持不变；本版的全部文件均位于 `chaoxing-video-runner-universal-v2.1.2`。

本版保留视频真实播放功能，并新增学习通章节内官方文档查看器任务点处理，覆盖 PDF、PPT、Word 等由 `/ananas/modules/pdf/index.html` 打开的文档。它不会处理测试、作业、考试或按分钟累计的“课程阅读”任务。

## 安装或升级

1. 打开 Edge 的 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 先禁用已经启用的旧版本；旧文件夹无需删除。
4. 点击“加载解压缩的扩展”。
5. 选择 `chaoxing-video-runner-universal-v2.1.2` 文件夹。
6. 确认扩展名称为“学习通课程任务播放器（通用版）”，版本为 `2.1.2`。
7. 刷新已经打开的学习通课程页面。

新版本新增 `notifications` 权限，只用于课程全部完成和文档连续失败5次后显示系统桌面通知。扩展不读取或保存账号密码。

## 使用方法

1. 在 Edge 中正常登录学习通。
2. 手动进入要处理的课程，打开地址包含 `/mycourse/studentstudy`、`courseId` 和 `clazzid` 的章节学习页面。
3. 在右上角面板中选择视频倍速和文档模式。
4. 默认文档模式为“自动处理PDF/PPT/Word”；如只需要原有视频功能，可选择“仅处理视频”。
5. 点击“开始 / 继续”。扩展会扫描全部叶子章节，建立视频与文档任务清单，然后依次处理未完成项目。
6. 查看面板中的视频、文档、成功和失败统计；需要时可导出失败记录与完整日志。

## 文档完成规则

- 只识别带学习通正式任务 `jobid`、且使用官方文档查看器的文档；仅含内部 `_jobid` 的普通附件不会被误计为任务点。
- 扩展在官方查看器的 `panView` 阅读区域逐页滚动到文档底部，让平台自己的滚动监听器触发完成；不直接构造隐藏完成请求。
- 文档页面加载、图片解码、DOM变化和完成标记均由事件监听驱动；不再依赖每页250毫秒的连续定时器，标签页在后台时仍可继续。
- 页面图片导致文档高度继续增长时，扩展会自动重新计算并再次滚到真实底部。
- 查看器处理结束后，扩展重新打开所在章节，并检查课程页的 `ans-job-finished` 或“任务点已完成”标记。
- 只有服务器重新呈现为已完成的文档才计入成功统计。
- 如果学校的查看器不显示页码或使用单页滚动模式，扩展会执行查看器自己的完成动作，再以服务器状态为准。
- 升级到本版时旧任务清单会自动失效并重新扫描，避免继续处理仅含 `_jobid` 的旧附件记录。
- 如果章节中的文档节点临时消失，扩展会自动重开章节两次；确认已不再是正式任务点后自动修复清单并继续，无需等待5次或人工删除状态。
- 同一章节存在多份文档任务时，每一份都会重新加载独立的官方查看器节点并按清单顺序处理，不会停在第一份。

## 重试与暂停

- 文档查看器加载、翻页、章节重开或完成核验失败后等待10秒重试。
- 每个文档在首次失败后最多自动重试5次。
- 连续重试5次仍失败时，当前课程整体暂停，面板记录失败原因，并显示高优先级桌面通知。
- 其他课程标签页继续运行，不受该课程暂停影响。
- 人工处理页面问题后点击“开始 / 继续”，该文档获得新的一轮5次重试机会。
- 视频沿用 `2.0.0` 的重试与跳过规则。

## 状态面板

- **总体进度**：最终已完成任务数 / 已识别任务总数。
- **视频**：视频完成数 / 视频总数。
- **文档**：PDF、PPT、Word 等文档完成数 / 文档总数。
- **成功 / 失败**：本轮成功任务数和当前未解决异常数。
- **日志**：扫描、打开、翻页、重试、平台确认和最终核验过程。最终核验会显示章节进度、任务序号、任务类型、名称及“已完成/未完成/节点缺失”结果。
- **导出失败**：下载包含课程、进度、失败项目和日志的 JSON 文件。

## 桌面通知

以下情况会显示系统通知：

- 全部视频和文档经过最终核验并完成；
- 某个文档连续重试5次仍未完成，当前课程被暂停。

如果没有看到通知，请检查 Windows 的 Edge 通知权限和“勿扰”设置。

## 多课程与恢复

- 不同课程可以分别打开在多个标签页中并行运行。
- 同一门课程只允许一个标签页运行，避免重复控制。
- Edge 或页面重新载入后，扩展会重新扫描当前课程，并以平台实际完成状态继续处理。
- 没有重新打开的课程不会自行启动。
- 为保证长期后台运行，请在 Edge 的“永不让这些网站进入睡眠状态”中保留实际使用的学习通域名。扩展已经减少后台定时器依赖，但无法唤醒被浏览器完全冻结的标签页。

## 限制

- 当前仅匹配 `*.chaoxing.com` 下的学习通课程页与官方文档查看器。
- 学校自建的非 Chaoxing 域名镜像需要单独增加域名匹配规则后才能使用。
- 验证码、人脸识别、身份验证或禁止切屏提示必须人工处理；扩展检测到后会停止当前课程。
- “课程阅读”模块按分钟累计的阅读成绩不属于本版文档任务功能。

## 常见问题

### 没有识别到文档

确认文档是章节内带任务点的 PDF、PPT 或 Word，并且打开后使用学习通官方文档查看器。普通附件和资料下载不会进入任务清单。

### 文档显示已翻完但没有计入成功

平台完成状态可能尚未同步。扩展会重新打开章节并等待确认；连续失败后会暂停，而不会把未确认项目误记为成功。若日志来自较早版本，请加载 `v2.1.2` 文件夹并刷新课程页；本版会自动清除旧清单。

### 页面没有面板

确认页面地址包含 `/mycourse/studentstudy`，确认只启用了一个版本，然后刷新课程页面。

### 如何保留或切回旧版

旧版目录保持不变。在 `edge://extensions/` 中禁用 `2.1.2`，再重新启用所需旧版本即可。不要同时启用两个通用版控制同一个页面。
