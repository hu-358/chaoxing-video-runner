# 认证测试备注（粘贴稿）

版本：2.2.0

本扩展为独立开发的非官方工具。它只在用户已经登录并手动打开的学习通 HTTPS 课程页面中运行。用户完成首次使用确认并点击“开始 / 继续”后，扩展会扫描章节，自动播放并静音视频，使用页面提供的倍速选项，通过官方文档查看器逐页浏览文档，切换到后续任务，并以课程页面重新呈现的状态核验完成结果。

由于学习通课程账号通常与学校或机构身份绑定，发布者无法合法提供可共享的真实学校账号和密码。为了使主要界面、安全边界和工作流程可测试，本包提供了完全离线的审核演示：

1. 安装扩展后会自动打开首次使用说明。
2. 也可点击工具栏中的扩展图标。
3. 点击“离线审核演示”。
4. 演示页面使用虚构课程数据，不连接学习通，也不会产生真实学习记录。
5. 可在地址末尾分别添加 `?scene=overview`、`?scene=video`、`?scene=document`、`?scene=blocked` 查看不同状态。

如果审核人员拥有可合法使用的学习通账号，可手动打开地址包含 `/mycourse/studentstudy`、`courseId` 和 `clazzid` 的课程页。首次确认后仍需在每次页面打开或刷新时由审核人员点击“开始 / 继续”，扩展不会自动恢复运行。

安全与范围说明：

- 不处理考试、测验、作业、讨论或问卷。
- 不绕过验证码、人脸识别、身份验证或禁止切屏提示；检测到相关提示会暂停。
- 不直接构造隐藏完成请求，完成状态以页面重新呈现的结果为准。
- 不读取密码或 Cookie，不拦截网络请求。
- 无开发者服务器、遥测、广告、应用内购买或远程代码。
- 本地保存的数据可通过课程面板或扩展菜单清除。
- 系统通知不包含课程、章节或任务名称。

权限：

- `storage`：本地保存首次确认、设置、任务进度和日志。
- `notifications`：显示不含课程信息的通用完成或失败通知。
- 两个 HTTPS 页面匹配范围：课程学习页与官方文档查看器。
