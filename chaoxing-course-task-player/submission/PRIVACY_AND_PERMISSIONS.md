# Partner Center 隐私与权限填写稿

## Single Purpose Description

在用户主动登录、打开并确认开始的学习通课程页面中，按照页面呈现的任务顺序控制官方视频播放器和文档查看器，处理并核验视频与文档任务进度。

## storage 权限理由

用于在当前 Microsoft Edge 浏览器本地保存首次使用确认、用户选择的倍速和文档设置、课程与班级标识、课程和任务名称、任务进度、失败状态、运行日志、面板位置以及同课程标签页互斥锁。数据不会通过扩展传输给开发者或第三方，用户可清除当前课程或全部本地数据。

## notifications 权限理由

用于在用户主动启动的课程处理全部完成，或因连续失败而暂停时显示系统通知。通知只包含通用的完成或失败提示，不包含课程名称、章节名称、任务名称、账号信息或推广内容。即使用户在系统中关闭通知，扩展的其余功能仍可正常工作。

## 网站访问理由

扩展只在 `https://*.chaoxing.com/mycourse/studentstudy*` 课程学习页面和 `https://*.chaoxing.com/ananas/modules/pdf/index.html*` 官方文档查看器中运行。访问用于读取章节、视频和文档任务结构，控制页面内的官方播放器与文档查看器，并读取页面重新呈现的完成状态。扩展不在其他网站运行，不读取登录密码或 Cookie，不拦截网络请求。

## 远程代码

选择：`No, I am not using remote code.`

说明：所有 JavaScript、HTML、CSS 和图标均包含在扩展包中。扩展不下载、解释或执行远程 JavaScript、WebAssembly 或动态规则。

## 数据使用披露原则

Partner Center 的数据类型名称可能随后台更新。提交时不得选择“完全不访问数据”，而应按当时页面的实际选项披露下列行为：

- 网站内容：课程、章节、视频和文档任务名称及页面显示的完成状态。
- 网站活动或用户活动：任务进度、播放进度、处理状态与错误日志。
- 标识符：课程 ID、班级 ID 和任务 ID；这些标识仅用于区分本地任务。
- 用户设置：倍速、文档模式、面板位置与首次确认状态。

不选择密码、身份验证信息、Cookie、联系方式、精确位置、健康、财务或支付信息。若后台将“本地访问”和“开发者收集”分开询问，仍应说明扩展会在本地访问和存储上述数据，但开发者不接收这些数据。

## 数据使用认证

仅勾选与下述事实一致的认证项：

- 数据仅用于清晰披露的用户可见功能。
- 不出售、共享或用于广告、画像、信用或资格判断。
- 不向开发者或第三方传输。
- 不用于与核心功能无关的目的。
- 用户可清除数据。
- 隐私政策与实际实现保持一致。
