# 变更日志

## 2.2.0 - 2026-09-04

### 新增

- 首次使用确认页和明确的自动化功能披露。
- 扩展菜单、内置隐私说明与离线审核演示。
- 清除当前课程数据和清除全部本地数据功能。
- 通用隐私通知，不再显示课程、章节或任务名称。
- GitHub Pages 产品、隐私与支持页面。
- Edge 商店素材、提交文案、审核备注和可复现打包脚本。

### 变更

- 合并 2.1.7 的后台生命周期计时、事件驱动播放器停滞判断、标签实例课程锁和标签关闭清理。
- 每次课程页面打开或刷新后强制暂停，必须由用户重新点击开始。
- 仅匹配 HTTPS 学习通页面。
- 移除冗余的全站门户内容脚本和显式广域主机权限。
- 加固父页面与官方文档查看器之间的消息来源校验。
- 状态数据结构升级到版本 5。

### 保留

- 真实播放视频并使用页面提供的倍速。
- 官方文档查看器逐页浏览和服务器状态核验。
- 多课程独立运行、同课程标签页互斥和失败重试。
- 考试、作业与人工验证拦截。
