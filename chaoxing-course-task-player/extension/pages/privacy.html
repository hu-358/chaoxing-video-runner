隐私说明

学习通课程任务播放器（通用版）

生效日期：2026年9月4日　版本：1.0

摘要：扩展不使用开发者服务器，不包含广告或分析工具，不向开发者或第三方传输课程数据；运行状态仅保存在用户当前的 Microsoft Edge 浏览器本地。

处理的数据

在用户主动启用并打开课程后，扩展会读取课程名称、课程与班级标识、章节名称、视频或文档任务名称、任务完成状态和播放器进度；并在扩展本地存储中保存上述任务状态、用户选择的设置、失败原因和运行日志。

不处理的数据

扩展不读取、保存或传输学习通密码、Cookie、手机号、真实姓名、身份证件、支付信息，也不创建开发者账号系统。

处理目的与方式

这些数据仅用于执行用户主动发起的课程任务处理、在页面上显示进度、避免同一课程重复运行、恢复非运行设置以及供用户在本机排查失败原因。扩展不进行广告分析、用户画像、数据出售或数据共享。

存储、保存期限与删除

数据存放在 Microsoft Edge 提供的 chrome.storage.local 本地扩展存储中，不会由扩展同步到开发者服务器。数据保留至用户点击“清除当前课程数据”“清除全部本地数据”或卸载扩展。用户也可以主动导出失败记录；导出的 JSON 文件由用户自行保管。

权限用途

  • storage：保存首次使用确认、运行设置、课程任务状态与本地日志。
  • notifications：在任务完成或遇到问题暂停时显示不含课程名称的通用系统通知。
  • 学习通 HTTPS 页面访问：读取课程任务结构并控制页面内的官方视频播放器和文档查看器。扩展不在其他网站运行。

未成年人

本扩展不专门面向儿童，不要求用户提供年龄，也不会向开发者传输未成年人数据。未成年人应在监护人指导下，并在学校和课程规则允许的范围内使用。

第三方服务

扩展的核心功能不连接开发者或分析服务。用户主动访问公开的 GitHub 产品说明、源代码或支持页面时，相关网站可能依据其自身政策处理访问日志；该访问不是扩展核心功能所必需。

安全与变更

扩展不加载或执行远程代码。若未来增加新的数据类型、服务器、分析、广告或支付功能，将先更新本说明和商店披露，并在必要时重新征得用户确认。
