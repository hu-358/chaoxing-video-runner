常见问题

刷新后为什么没有继续？
为确保每次运行都由用户明确发起，页面打开或刷新后会暂停，需要再次点击“开始 / 继续”。

为什么遇到验证会停止？
扩展不绕过验证码、人脸识别、身份验证或禁止切屏提示，必须由用户本人处理。

数据如何删除？
课程面板可清除当前课程数据；扩展菜单可清除全部本地数据；卸载扩展也会删除扩展存储。

能否处理考试或作业？
不能。考试、测验、作业、讨论和问卷不在功能范围内。

本扩展为独立开发的非官方工具。
