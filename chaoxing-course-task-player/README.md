# 学习通课程任务播放器（通用版）

当前商店候选版本：`2.2.0`

公开源码仓库：<https://github.com/hu-358/chaoxing-video-runner>

本扩展为独立开发的非官方工具。它在用户主动登录、打开课程并点击开始后，扫描课程中的视频和官方文档任务，按页面顺序控制播放器与文档查看器，并在本地显示和保存处理进度。

## 重要说明

- 扩展会自动播放并静音视频、选择页面提供的倍速、逐页浏览官方文档，并切换到后续任务。
- 扩展不处理考试、测验、作业、讨论或问卷。
- 扩展不会绕过验证码、人脸识别、身份验证或禁止切屏提示；检测到相关提示时会暂停。
- 扩展不构造隐藏完成请求，完成状态以课程页面重新呈现的状态为准。
- 用户应自行确认使用方式符合学习通、所在学校和课程规则。

## 隐私

扩展不使用开发者服务器、广告或分析工具，也不读取密码和 Cookie。课程名称、课程与班级标识、章节和任务名称、进度、设置及错误日志只保存在当前 Edge 浏览器本地。用户可清除当前课程数据或全部扩展数据。

详细内容见[隐私政策](docs/privacy/index.html)。

## 本地安装与测试

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”。
4. 选择仓库中的 `extension` 文件夹。
5. 完成首次使用确认，再手动打开自己的课程页面。

不需要学习通账号即可从扩展菜单打开“离线审核演示”。演示数据完全虚构，不连接学习通，也不会产生真实记录。

## 构建商店包

在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-edge-package.ps1
```

输出文件位于 `release/`。构建脚本只打包运行所需文件，并验证 `manifest.json` 位于 ZIP 根目录。
