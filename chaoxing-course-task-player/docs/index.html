学习通课程任务播放器（通用版）

用户手动登录并打开课程后，由用户主动启动，按课程页面顺序播放视频、浏览官方文档并核验任务状态。

隐私政策支持与常见问题
本扩展为独立开发的非官方工具。用户应自行确认使用方式符合学习通、所在学校和具体课程的规则。

主要功能

  • 扫描用户手动打开的课程及章节任务。
  • 真实播放并静音视频，使用页面提供的倍速选项。
  • 通过官方文档查看器逐页浏览 PDF、PPT 和 Word 文档。
  • 最终重新核验课程页面显示的完成状态。
  • 在当前 Edge 浏览器本地保存进度和错误日志。

明确限制

扩展不处理考试、测验、作业、讨论、问卷或计时阅读，不绕过验证码、人脸识别、身份验证或禁止切屏提示，也不直接构造隐藏完成请求。遇到人工验证时会暂停并等待用户处理。

数据与费用

扩展完全免费，无广告、无开发者服务器、无分析工具、无远程代码。课程任务数据只保存在用户的 Edge 本地，可由用户随时清除。
